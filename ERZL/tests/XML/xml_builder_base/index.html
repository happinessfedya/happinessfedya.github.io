    Тесты XMLBuilderBase

    Эта страница показывает тесты из общего test-файла. Команда, на которой основаны сценарии:

    python -m pytest -vv -s tests/xml/test_xml_builder_base.py

    Флаг -s здесь не добавляет пользовательской печати: модуль не выводит свои сценарии, поэтому в pytest видны только имена тестов и статусы PASSED. Ниже раскрыто, какие именно базовые SOAP-сценарии, low-level ошибки и архитектурные ограничения стоят за этими статусами.

    Докстринг модуля

    Тесты для `XML.xml_builder.XMLBuilderBase`.

Модуль проверяет базовый контракт XML-builder-а: сборку общего SOAP-каркаса,
получение service namespace из конфигурации и сериализацию готового дерева в
байты.

Файл нужен для фиксации минимальной ответственности `XMLBuilderBase` и защиты
от регрессий в общей инфраструктуре XML-сборки.

    Исходный код больше не вынесен в один общий блок сверху. Ниже у каждого сценария есть отдельный раскрывающийся блок с кодом именно того теста, который документируется.

    Зачем этот класс

    XMLBuilderBase живет в XML-слое и обслуживает только общую инфраструктуру сборки XML. Он берет xml_config и дает наследникам три базовые операции:

    • _build_envelope() создает общий SOAP Envelope с Header и Body;
    • _finalize_xml(envelope) сериализует готовое дерево в bytes;
    • _ser_ns() достает service namespace из конфигурации.

    Этот класс не:

    • не знает о request-specific DTO вроде search_pairs или ClientContainerCfg;
    • не заполняет пользовательские поля;
    • не валидирует бизнес-данные;
    • не отправляет XML и не парсит ответ;
    • не скрывает low-level ошибки lxml или KeyError в испорченном конфиге.

    Шестой тест: _finalize_xml не маскирует lxml.TypeError для невалидного объекта

    Докстринг теста

    `_finalize_xml` не валидирует входной объект и оставляет low-level ошибку `lxml`.

    Этот тест нужен, чтобы явно отделить обязанности. XMLBuilderBase не проверяет, что ему передали именно настоящий etree._Element; он просто делегирует сериализацию в lxml.etree.tostring(...). Поэтому наружу выходит именно TypeError с текстом про невозможность сериализации.

    Показать код тестаСкрыть код теста 
    def test_finalize_xml_propagates_lxml_type_error_for_invalid_object(self) -> None:

    # Arrange

    bad_envelope = cast(etree._Element, object())

    # Act / Assert
