    Тесты ClientSection

    Эта страница показывает тесты из общего test-файла. Команда, на которой основаны сценарии:

    python -m pytest -vv -s tests/xml/test_client_section.py

    Флаг -s здесь не добавляет пользовательской печати: модуль не выводит свои сценарии, поэтому в pytest видны только имена тестов и статусы PASSED. Ниже раскрыто, какие именно XML-сценарии, controlled errors и архитектурные ограничения стоят за этими статусами.

    Докстринг модуля

    Тесты для `XML.xml_builder.ClientSection`.

Модуль проверяет контракт сборки client-блока: выбор namespace для корневого
контейнера, построение вложенных путей, поведение при пустой конфигурации и
контролируемые ошибки builder-а.

Файл нужен для фиксации изоляции `ClientSection` от pipeline-, source- и
transport-слоёв и для защиты от регрессий в логике сборки клиентского XML.

    Исходный код больше не вынесен в один общий блок сверху. Ниже у каждого сценария есть отдельный раскрывающийся блок с кодом именно того теста, который документируется.

    Зачем этот класс

    ClientSection живет в XML-слое и отвечает только за сборку статического client-блока внутри уже существующего XML-дерева. Класс берет:

    • xml_config с namespace-картой и service-prefix;
    • xml_client_data с root_container_name, flat_container, optional_ns_prefix и container_paths;
    • родительский XML-элемент parent.

    На выходе он:

    • создает корневой client-контейнер;
    • при необходимости строит промежуточные вложенные контейнеры;
    • записывает leaf-значения в XML;
    • возвращает корневой элемент client-блока или None в _maybe_build_client.

    Этот класс не:

    • не выбирает данные для запроса;
    • не работает с DTO pipeline-слоя;
    • не отправляет XML;
    • не парсит ответ;
    • не скрывает неожиданные runtime-ошибки приведения типов.

    # Arrange
    section, xml_config, _ = _make_section(optional_ns_prefix="alt")
    parent = _make_parent(xml_config)
    alt_ns = xml_config.namespaces["alt"]

    # Act
    client_root = section._build_client(parent)

    # Assert

    Седьмой блок: проблемные значения client-полей дают XMLBuilderRetryError или прямой AttributeError

    Докстринг теста test_empty_or_whitespace_client_value_raises_retry_error

    Пустое обязательное значение client-блока даёт `XMLBuilderRetryError`.

    Докстринг теста test_non_string_client_value_propagates_runtime_attribute_error

    Не-`str` значение ломается на `.strip()` без отдельной типовой защиты секции.

    Первый сценарий документирует контролируемую бизнес-ветку builder-а: строка не может быть пустой или состоять только из пробелов. Второй фиксирует, что ClientSection не делает отдельную type-check в духе isinstance(val, str), а опирается на .strip(), поэтому нестроковое значение ломается как обычная runtime-ошибка Python.
