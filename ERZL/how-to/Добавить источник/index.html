    Добавить источник

    Порядок действий

    Новый источник в этом проекте подключается по одной и той же схеме:

    1. добавить DTO строки и конфиг источника;
    2. реализовать класс чтения источника;
    3. подготовить маппинг колонок источника в PersonFields;
    4. собрать bootstrap-конфиг;
    5. подключить источник в LoadContextStep;
    6. передать новый LoadContextStep в orchestrator.

    Итоговая цепочка выглядит так:

    Новый Source
-> DTO строки источника
-> RenameToSourceInputAdapter
-> SourceInput[PersonFields]
-> ERZLContextFactory
-> LoadContextStep
-> ERZLOrchestrator

    1. Добавить DTO и конфиг источника

    Файл: Source/source_core_types.py

    Сначала добавьте:

    • dataclass конфига источника;
    • dataclass одной строки источника.

    Пример для CSV

    from dataclasses import dataclass
from pathlib import Path
from typing import Dict

@dataclass(frozen=True)
class CSVSourceCfg:
    PathCSV: Path
    Encoding: str = "utf-8"
    Delimiter: str = ";"


@dataclass(frozen=True)
class CSVRowDTO:
    data: Dict[str, SourceValue]
    index: int

    Что должно получиться

    После чтения одна строка источника должна выглядеть так:

    CSVRowDTO(
    data={
        "fam": "Иванов",
        "im": "Иван",
        "snils": "123-456-789 00",
    },
    index=1,
)

    2. Реализовать класс источника

    Файл: Source/SourceData.py

    Нужно добавить класс, который читает внешний источник и возвращает Iterator[DTO_строки].

    Пример для CSV

    import csv
from typing import Iterator, Dict

from .source_core_types import CSVSourceCfg, CSVRowDTO, SourceValue


class CSVSource:
    def __init__(self, cfg: CSVSourceCfg):
        self._cfg = cfg

    def _getData(self) -> Iterator[CSVRowDTO]:
        with open(self._cfg.PathCSV, "r", encoding=self._cfg.Encoding, newline="") as f:
            reader = csv.DictReader(f, delimiter=self._cfg.Delimiter)

            row_idx = 1
            for row in reader:
                data: Dict[str, SourceValue] = {}

                for key, value in row.items():
                    if key is None or value is None:
                        continue

                    value = value.strip()
                    if value == "":
                        continue

                    data[key] = value

                if data:
                    yield CSVRowDTO(data=data, index=row_idx)

                row_idx += 1

    def run_getData(self) -> Iterator[CSVRowDTO]:
        yield from self._getData()

    Что важно сохранить

    Источник должен возвращать DTO строки в формате:

    dto.data
dto.index

    Это позволит сразу использовать существующий RenameToSourceInputAdapter.

    3. Подготовить маппинг колонок источника в PersonFields

    Файл: config/erzl.toml

    Нужно описать соответствие между полями нового источника и PersonFields.

    Изменение

    + [source_aliases.csv_main]
+ fam = "SURNAME"
+ im = "NAME"
+ otch = "PATRONYMIC"
+ dr = "DATE_BIRTH"
+ snils = "SNILS"
+ sex = "SEX_ID"
+ citizenship = "CITIZEN_CODE"

    После такого маппинга адаптер сможет превратить строку источника:

    {"fam": "Иванов", "im": "Иван", "snils": "123-456-789 00"}

    в канонический набор:

    {
    PersonFields.SURNAME: "Иванов",
    PersonFields.NAME: "Иван",
    PersonFields.SNILS: "123-456-789 00",
}

    4. Собрать bootstrap-конфиг

    Файл: config/bootstrap_core_types.py

    На этом шаге нужно:

    • собрать конфиг нового источника;
    • собрать RenameToSourceInputAdapterCfg.

    Изменение

    + _CSVMainSourceCfg = CSVSourceCfg(
+     PathCSV=Path(source_raw["PathCSV"]),
+     Encoding=source_raw.get("Encoding", "utf-8"),
+     Delimiter=source_raw.get("Delimiter", ";"),
+ )
+
+ _CSVMainRenameToSourceInputAdapterCfg = RenameToSourceInputAdapterCfg.field_from_alias(
+     alias_by_field=alias_raw,
+     field_enum=PersonFields,
+ )

    Потом конфиг нужно положить в BootstrapCfg.

    Изменение

      class BootstrapCfg:
      class ERZL:
          class Source:
+             CSV = _CSVMainSourceCfg

          class Adapters:
+             RenameToSourceInput = _CSVMainRenameToSourceInputAdapterCfg

    5. Подключить источник в LoadContextStep

    Файл: config/bootstrap.py

    Теперь нужно собрать рабочую цепочку:

    1. создать экземпляр нового Source;
    2. создать RenameToSourceInputAdapter;
    3. использовать ERZLContextFactory;
    4. собрать LoadContextStep.

    Изменение

    + from Source.SourceData import CSVSource
+ from Source.source_core_types import CSVRowDTO, PersonFields, ERZL_Context
+ from Adapters.Adapters import RenameToSourceInputAdapter
+ from Source.ContextBuilder import ERZLContextFactory
+ from Pipeline.pipeline_protocols import LoadContextStep
+
+
+ csv_source = CSVSource(BootstrapCfg.ERZL.Source.CSV)
+
+ rename_to_source_input_adapter = RenameToSourceInputAdapter[PersonFields](
+     BootstrapCfg.ERZL.Adapters.RenameToSourceInput
+ )
+
+ context_factory = ERZLContextFactory()
+
+ load_ctx_csv_person_erzl = LoadContextStep[CSVRowDTO, PersonFields, ERZL_Context](
+     csv_source,
+     rename_to_source_input_adapter,
+     context_factory,
+ )

    6. Передать новый шаг загрузки контекста в orchestrator

    Файл: config/bootstrap.py

    После того как появился новый LoadContextStep, его нужно передать в orchestrator.

    Изменение

      ERZLOrchestrator_CSV_PersonFields_Main = ERZLOrchestrator(
-     get_context=load_ctx_xlsm_person_erzl,
+     get_context=load_ctx_csv_person_erzl,
      get_attempt_data=get_attempt_data_step_person,
      build_search_xml=build_search_xml_step_person,
      build_create_xml=create_person_step,
      adapter_base=AdapterBase(),
      erzl_adapter=ERZLAdapter(),
      transport=transport_step,
      get_answer=answer_decision_step,
  )

    Минимальный набор файлов

    При добавлении нового источника обычно меняются:

    • Source/source_core_types.py
    • Source/SourceData.py
    • config/erzl.toml
    • config/bootstrap_core_types.py
    • config/bootstrap.py

    Результат

    После подключения нового источника цепочка должна работать так:

    1. источник читает внешний файл или API;
    2. возвращает DTO строки;
    3. RenameToSourceInputAdapter собирает SourceInput[PersonFields];
    4. ERZLContextFactory создаёт ERZL_Context;
    5. дальше запускается стандартный ERZL-пайплайн.

    Пример промежуточного результата после адаптера

    SourceInput[PersonFields](
    attributes={
        PersonFields.SURNAME: "Иванов",
        PersonFields.NAME: "Иван",
        PersonFields.SNILS: "123-456-789 00",
    },
    index=1,
)
